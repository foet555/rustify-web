Install

Up and running in under a minute

Both builds install the same way every time. Pick your platform and follow the steps below.

Windows

Rustify-Setup-1.4.0.exe
  1. 1

    Download the installer

    Save the .exe file wherever you keep installers.

  2. 2

    Run it

    Double-click the file and follow the prompts. No restart is needed.

  3. 3

    Open Rustify

    Launch it from the Start menu or the desktop shortcut.

Seeing a SmartScreen warning? New builds don't have download reputation yet. Choose More info → Run anyway.

Android

Rustify-1.4.0.apk
  1. 1

    Download the APK

    It lands in your Downloads folder.

  2. 2

    Allow the install

    When Android asks, permit installs from your browser under Settings → Apps → Special access → Install unknown apps.

  3. 3

    Tap Install

    Open the downloaded file and confirm. Rustify appears in your app drawer.

Updates: install the new APK over the top and your data stays put. You can revoke the install permission again afterwards.

FAQ

Common questions

Is Rustify free?

Yes. Both downloads are free, with no account, trial period or subscription attached.

Why isn't it on Google Play or the Microsoft Store?

Rustify is distributed directly from this page so new versions can ship the moment they're ready, without waiting on store review.

Windows says the app isn't recognised. Is it safe?

That's SmartScreen reputation, not a virus report — a freshly published build hasn't been seen often enough yet. Confirm the file name matches the one on this page, then choose More info → Run anyway.

Will updating delete my data?

No. Run the new installer, or install the new APK over the old app, and your settings stay in place.

Does it need an internet connection?

No. Rustify works offline; a connection is only needed for updates and any online-only features you switch on.

How do I uninstall it?

On Windows, open Settings → Apps → Installed apps, find Rustify and choose Uninstall. On Android, long-press the icon, then App info → Uninstall.
